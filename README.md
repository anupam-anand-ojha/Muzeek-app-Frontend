Muzeek App

Muzeek is a full-stack music streaming platform where users can discover and stream songs, while artists can upload and manage their own music inspired by modern platforms like Spotify,Gaana,Savan etc....

Features

• Role-Based Authentication  
• Users can browse and stream music  
• Artists can upload, edit, and manage songs  

• Music Streaming  
• Smooth audio streaming experience  
• Browse tracks with song details  

• Song Upload System  
• Upload songs with title, thumbnail, artist details, and audio files  

• Artist Dashboard  
• Manage uploaded content  
• Update or remove songs easily  

Tech Stack

• Frontend: React.js, Axios, React Router  
• Backend: Node.js, Express.js  
• Database: MongoDB  
• Media Storage: Cloudinary / ImageKit  

Project Structure

• /frontend → Frontend application (UI, components, pages)  
• /backend → Backend API (routes, controllers, models)  

Installation & Setup

• Clone the repository

git clone https://github.com/your-username/muzeek-app.git

• Frontend Setup

cd frontend  
npm install  
npm run dev  

• Backend Setup

cd backend  
npm install  
npm run dev  

API Endpoints

• POST /signup → Register a new user  
• POST /login → Authenticate user  
• GET /songs → Fetch all songs  
• POST /upload → Upload a song (Artist only)  

Deployment

• Frontend → Vercel  
• Backend → Render
